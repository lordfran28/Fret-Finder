# Songs

Every song on Fret Finder is a file in this folder. The site lists whatever is here.

**To add songs from your computer:** put MusicXML (.musicxml, .xml, .mxl), MIDI (.mid) or Guitar Pro (.gp, .gp5) files in this folder, then commit and push in GitHub Desktop. They show up on the site, on every device, a minute or two later. Subfolders are fine.

**To add songs from the site:** use *Add a song* on a device that's connected on the owner page. The site puts the file here for you.

The file name becomes the song's title. A file ending in `.ff.json` next to a song holds what you set on the site: its title, settings, and any notes you moved to another string. Leave those in place; delete one together with its song.

`index.json` is rewritten automatically after every change. Don't edit it by hand.
